# SOC Incident Investigation Lab

## 🎯 Project Overview
This project simulates a real-world Security Operations Center (SOC) environment to practice threat detection, log analysis, and incident investigation.  

The lab replicates attacker and victim behavior in a controlled virtual environment and uses a SIEM platform to analyze security events.

## 🧰 Tools Used

- Windows 11 (Endpoint)
- Kali Linux (Attack simulation)
- Sysmon (Endpoint telemetry)
- Splunk Enterprise (SIEM)
- Atomic Red Team (Attack simulation framework)

---

## 🎯 Objectives

- Build a realistic SOC home lab environment
- Generate and analyze malicious activity
- Collect and investigate Windows event logs
- Detect suspicious behavior using Splunk queries
- Map findings to MITRE ATT&CK framework
- Produce incident investigation reports
